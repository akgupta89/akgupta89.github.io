Doomwall

A Chrome extension that blocks the sites you keep opening — out of habit, boredom, or whatever it is today — and shames you a little when you try.

Add to Chrome GitHub Connect your agent →

What it does

  • Rules. Block a domain, just a path on it (youtube.com/shorts), or carve out an exception (reddit.com/r/programming). Optionally only during a time window.
  • Blocked page. A guilt line, how many times you tried today and overall, and roughly how much time you got back.
  • Bypass. One tab gets through when you admit you have no self-control. Capped per day if you want.
  • Pause. Turn everything off for a few minutes when you actually need a site.
  • Activity. Daily and all-time numbers, a 14-day chart, time spent per site.
  • Agent-ready. Every control is a WebMCP tool, so your AI agent can manage the wall for you.
  • Private. Everything stays in your browser. No accounts, no servers.

Install

  1. Add it from the Chrome Web Store (or load the repo unpacked).
  2. Click the toolbar icon → Rules → Add rule.
