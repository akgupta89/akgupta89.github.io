Stuff I built for fun

  • Prime Visualizer (source) converts seemingly random prime numbers into fun patterns.
  • Light Screen (source) turns monitors into illumination sources using the broadcast channel API create a global state across multiple windows.
  • fast-prime-gen (source) is an npm package that generates sequential primes on demand through a generator.
  • Doomwall is a Chrome extension that blocks the sites you open on autopilot and shames you a little when you try.
